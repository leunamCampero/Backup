# References

Notebooks 06 and 07b compare the network model with, and borrow car/CO₂ equations from, two model documents
written by colleagues:

* `book.tex` — first-order bike mode-share model and the *Backcasting* chapter (optimal control of cycling investment);
* `bicycle_model.tex` — *Cycling circulation, simplified model*: calibration of the lane-efficiency parameter *k*,
  scenario table (α, P∞, ξ, r_BC) and abatement-cost sensitivity.

They are unpublished work and are **not distributed** in this repository (the `.tex` files placed in this folder
are ignored by git). The equations used are restated in the notebooks.

## Method references

* Mekuria, M. C., Furth, P. G., & Nixon, H. (2012). *Low-Stress Bicycling and Network Connectivity*.
  Mineta Transportation Institute, Report 11-19 — original Level of Traffic Stress method.
* Furth, P. G., Mekuria, M. C., & Nixon, H. (2016). Network connectivity for low-stress bicycling.
  *Transportation Research Record*, 2587, 41–49.
* Boeing, G. (2017). OSMnx: New methods for acquiring, constructing, analyzing, and visualizing complex street
  networks. *Computers, Environment and Urban Systems*, 65, 126–139.
* Papke, L. E., & Wooldridge, J. M. (1996). Econometric methods for fractional response variables.
  *Journal of Applied Econometrics*, 11(6), 619–632 — fractional logit used in step 3.
